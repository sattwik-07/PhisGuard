# 🛡️ PhishGuard — AI Phishing URL Detector

A professional, client-side phishing URL detection web application powered by
machine learning. Analyses 29 lexical and structural URL features instantly,
with zero data leaving your browser.

## Deployment to GitHub Pages

### Step 1 — Fork or clone this repo

```bash
git clone https://github.com/<your-username>/phishguard.git
cd phishguard
```

### Step 2 — Enable GitHub Pages

1. Go to your repository on GitHub
2. Click **Settings** → **Pages** (left sidebar)
3. Under **Source**, select **Deploy from a branch**
4. Set branch to `main` and folder to `/ (root)`
5. Click **Save**

Your site is now live at `https://<your-username>.github.io/phishguard`
in about 60 seconds. It runs in **heuristic mode** immediately — no model
needed.

## Enabling Full ML Mode (Recommended)

Heuristic mode is accurate for obvious phishing patterns. For the full
Random Forest model (~97% accuracy), follow these steps once:

### Step 3 — Download the dataset

Download **PhiUSIIL Phishing URL Dataset** from UCI Machine Learning Repository:

```
https://archive.ics.uci.edu/dataset/967/phiusiil+phishing+url+dataset
```

Save the CSV file as `phishing_dataset.csv` inside the project folder.

The dataset contains 377,751 URLs (235,795 phishing + 141,956 legitimate),
collected from PhishTank, OpenPhish, Tranco, and Common Crawl.

### Step 4 — Install Python dependencies

```bash
pip install -r requirements.txt
```

Requires Python 3.9+.

### Step 5 — Train and export the model

```bash
python train_export.py --dataset phishing_dataset.csv
```

This will:
- Extract 29 features from every URL (~2 minutes on a modern CPU)
- Train a Random Forest (200 trees)
- Evaluate on a held-out 20% test split and print metrics
- Export 50 trees to `model.json` (~1–2 MB)

**Speed tip:** To train on a 50,000-row sample for faster testing:
```bash
python train_export.py --dataset phishing_dataset.csv --sample 50000
```

**Output options:**
```
--dataset   Path to CSV file (required)
--output    Output path for model JSON  (default: model.json)
--n-trees   Number of trees to export   (default: 50)
--sample    Sample N rows for speed     (default: use all)
```

### Step 6 — Commit and push model.json

```bash
git add model.json
git commit -m "Add trained Random Forest model"
git push
```

GitHub Pages redeploys automatically. The site switches to
**🤖 ML Model Active** mode on the next page load.

## How It Works

### Feature Extraction (features.js)

Every URL is parsed and 29 features are extracted in pure JavaScript —
no network calls, no server:

| Category | Features |
|---|---|
| **Length** | URL length, domain length, path length, query length |
| **Character counts** | Dots, hyphens, underscores, slashes, digits, letters, special chars, `@`, `?`, `&`, `=`, `%` |
| **Ratios** | Digit-to-letter ratio |
| **Structural** | IP address in hostname, `@` symbol, double-slash redirect, HTTPS, port, subdomain depth, TLD risk, suspicious keywords, URL shortener |
| **Entropy** | Shannon entropy of URL and domain (measures randomness/obfuscation) |
| **Query** | Number of query parameters |

### Classification (classifier.js)

**ML Mode** (`model.json` present):
- Loads a scikit-learn Random Forest exported as JSON
- Each of the 50 trees votes on the URL
- Phishing probability = average vote fraction
- Automatic: site detects and loads `model.json` on startup

**Heuristic Mode** (fallback, always available):
- 26 weighted rules derived from feature-importance analysis
- S-curve normalisation for calibrated probability output
- No training data or internet required

### Model Export (train_export.py)

The Python script exports sklearn's internal tree structure
(`children_left`, `children_right`, `feature`, `threshold`, `value`)
as compact JSON. The JavaScript traversal mirrors sklearn's
`DecisionTreeClassifier.predict()` exactly.

## Local Development

No build step required. Open directly in a browser:

```bash
# Option A — Python simple server (recommended, fixes fetch() CORS for model.json)
python -m http.server 8000
# then open http://localhost:8000

# Option B — VS Code Live Server extension
# Right-click index.html → Open with Live Server

# Option C — Node.js
npx serve .
```

> **Note:** Opening `index.html` as a `file://` URL will cause the
> `model.json` fetch to fail due to browser CORS restrictions.
> Always use a local HTTP server during development.

## Customisation

**Change colour theme:**
Edit CSS variables at the top of `style.css` under `:root { … }`.

**Add more features:**
1. Add the extraction logic to `extractFeatures()` in `js/features.js`
2. Add the display metadata to `FEATURE_DISPLAY` in `js/features.js`
3. Add the same feature name to `FEATURE_NAMES` in `train_export.py`
4. Retrain and re-export `model.json`

**Change number of exported trees:**
```bash
python train_export.py --dataset phishing_dataset.csv --n-trees 30
```
Fewer trees = smaller file, slightly lower accuracy.

## Troubleshooting

| Problem | Fix |
|---|---|
| Site shows "Heuristic Mode" after pushing model.json | Hard-refresh the page (Ctrl+Shift+R). GitHub Pages CDN may cache for ~1 min. |
| `fetch` fails when opening index.html directly | Use `python -m http.server 8000` instead of `file://` |
| `train_export.py` can't find URL/label columns | Check your CSV column names; rename them to `url` and `label` |
| model.json is too large (>5 MB) | Reduce trees: `--n-trees 25` |
| Training is slow | Use `--sample 80000` for a large-enough representative sample |
